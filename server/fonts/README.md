# Embedded watermark font

- Font: Noto Sans SC Regular, official Noto CJK project, unmodified.
- Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/SC/NotoSansSC-Regular.otf
- Download: 2026-10-22.
- SHA-256: `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`.
- License: SIL Open Font License 1.1; full copyright and license text in `../licenses/NotoSansSC-OFL.txt`.

The server embeds the original font for identical Chinese watermark rendering on Windows and Linux. No operating-system font installation or remote font request is required. The font is not separately installed on clients.
