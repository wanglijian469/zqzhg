# 中企展馆 v1.11.0 / 大陆农机 1.11.0（51）

本版将平台厂商分类与企业自定义产品分类分开，网页与App同步支持分类管理、发布时新增并选中、展厅分类筛选和数量、名称搜索。包含产品两级面包屑、企业经营信息与生产能力布局、企业重名校验和头条验证文件。数据库由Schema30增量升级至31，迁移保留历史审核JSON、媒体、正文和旧平台分类索引。

升级包适用于现有Linux amd64阿里云ECS。包含Go程序、构建网页、原77项开发演示边界快照、原签名正式APK及可回退升级脚本。边界沿用演示来源说明，130571仍按缺少轮廓处理，不伪造地图资质。

1. 解包后运行 `sha256sum -c SHA256SUMS` 和 `python3 upgrade.py check`。
2. 运行 `python3 upgrade.py backup`、`stage`、`candidate`。脚本备份数据库、媒体、原程序和配置；以恢复副本、正式服务账号、生产配置和独立Nginx验证Schema31迁移、审核快照不变、企业分类和全国→河北→邢台→宁晋四级地图。
3. 浏览器验收候选的桌面/手机地图、历史导航和边界失败重试后运行 `python3 upgrade.py apply`，复验正式HTTPS和官网下载清单。只重启中企展馆服务，保留共享服务、媒体、密钥、短信配置及持久站点验证文件。
4. 官网正式APK切换至1.11.0（51），旧正式包归档，既有候选下载保留。使用原包名 `com.zqzt.dalunongji` 和原签名，可覆盖安装；本版没有新增安卓实体设备验收，组件、签名和构建检查不能替代真机测试。

程序、网页和App下载回退：`python3 upgrade.py rollback`。回退不会导入旧数据库或降级Schema31；新表为增量添加，旧数据字段保持。恢复数据库需单独按私有备份流程操作。

本目录记录构建和升级步骤；是否已上线以配套 `deployment.json` 和最终上线回执为准。源码不包含生产数据库、私有媒体、密码或签名密钥。完整功能说明见 `docs/VENDOR_PRODUCT_CATEGORIES_20261115.md`。
