# 1.10.9 抖音播放修复及47版独立手机测试包

修复原生播放器遗漏的官方静态资源域名与路径；未知域名、HTTP、文件访问及自动导航仍禁止。去掉每条视频授权勾选，改为复用主动确认过的有效服务协议，不伪造逐条授权记录，所有账号保留后端校验。历史审核、配额、本地视频和协议审计保留，无数据库迁移。

网页及后端需经备份、独立恢复和生产代理验证后升级。47版为包名com.zqzt.dalunongji.editdev的独立测试App，可与正式App共存，固定连接正式域名；手机尚待复测。正式APK45和旧候选46下载保留。抖音仍由用户点击官方按钮开始播放。

升级器支持check、backup、stage、candidate、apply和rollback。回退只恢复程序、网页、下载和环境，不回灌旧库，不降级Schema30。沿用77项开发地图快照，发布前后验证真实四级边界、统计、手机布局及失败重试，不回退方块图。
