## 后续发布与回退

源码修改提交Git，APK作为Release附件发布；新版本必须重新核对包名、递增版本号、原签名、清单哈希及嵌入的正式HTTPS地址。使用 `scripts/publish-github-release.mjs <本机发布清单路径>` 上传准备好的附件；清单指定tag、commit、name、body及每个附件的path/name/size/sha256。认证通过本机Git凭据管理器读取，不将令牌写入项目。

ECS下载提升工具为 `deploy/linux/promote-android-download.py`，仅在备份完成、包已验证后执行。每次保留原包、配置、清单及数据库快照。修复应继续保留资料内容审核，不得回退为重新强制收集四项敏感材料；数据库备份仅供灾难恢复，不能覆盖升级后新增资料。Android已安装版本不能通过较低versionCode直接覆盖回退，优先交付versionCode高于42的修复包，避免卸载导致本机草稿丢失。
