## 回滚与恢复

普通回滚不恢复旧数据库、不删除文件、不运行删表脚本。存在 OSS 对象／上传会话／文件任务后，`read-fallback` 关闭上传和 worker，保留 Schema 39、私有签名读取、公开副本及逻辑 ID；不得直接退回不识别 RemoteKey 的 v1.12.3。只有确认尚无 OSS 数据时才能切回原程序，保留新增表及所有业务记录。
