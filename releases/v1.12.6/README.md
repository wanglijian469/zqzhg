已于2026-11-20部署阿里云ECS并完成正式HTTPS验收。交付版本：网站 v1.12.6、Schema40、Android 大陆农机 1.12.1+54。程序及内置网页源码提交为 `d977ba48d28dd842da50e1124ecbaffa3fd4fbb9`；发布标签还包含追加的部署记录和运维脚本。

## 使用变化

- 管理员进入“系统设置 → AI模型配置 → 内容提取规则”，分别编辑目录、企业、产品详情及复核规则。支持校验、历史查看和恢复后另存；校验不调用模型。每阶段最多6000字节，固定数据结构、原值、来源及权限约束不能覆盖。
- 新任务采用保存时的规则和模型快照。普通重试沿用原规则；“按最新规则重试未完成项”需要厂商明确选择。旧版失败任务同样支持此操作，已成功阶段保留原规则缓存。厂商不能选择模型，不会自动升级max。
- 单个阶段最多3次实际模型请求，格式修复和传输重试共用预算；失败单元单独保留，其他页面和产品继续处理。等待、租约和检查点落库，服务重启后可恢复。
- 已保存的有效企业草稿不因补识别目录页而重复调用或覆盖。产品区分结构变体；相同名称但来源区块不同的产品不会被误合并，重叠来源会提示核对。
- 已完成的产品可先分批确认提交。未完成项可重试或人工补齐；缺主图、分类、审核版本或核对说明时不能提交。人工编辑和已提交内容受到保护。
- 页面使用轻量状态查询、异常退避和断线重连。进度刷新保留未保存编辑，后台更新与人工修改冲突时要求明确选择。
- 公开产品不显示PDF页码、参数来源列、图纸页码和明确的画册来源标题；后台保留原件、来源、原值和审核问题。参数数值、单位和原始技术图不改写或重绘。
- 历史产品正文整理只生成私有更新草稿，经原平台审核后才生效。厂商确认不等于公开，测试资料不自动发布。

本轮不新增收费、充值或Token额度扣减模块，仅保留调用用量和费用估算记录。存储配额及原手工业务继续沿用现有设置。

## 接口与数据

新增管理员接口：`GET/PUT /api/v1/admin/settings/ai-prompts`、`GET .../history`、`POST .../preview`。保存携带当前 `version`、四阶段 `rules` 和 `note`，冲突返回409，厂商访问返回403。

`POST /api/v1/merchant/ai-import/tasks/:id/retry`增加 `unit_ids`、`prompt_policy`（original/latest）及 `prompt_version_id`。结果接口提供来源覆盖、工作单元、规则版本、待补原因及 `result_version`。所有任务、草稿、图片与提交操作继续按当前账号和企业隔离。

迁移 [040](../../server/migrations/040_ai_import_resilience.sql) 新增规则版本和工作单元表，以及任务快照、结果版本和草稿完成状态字段。企业和产品仍写入原 Content/Revision 业务库。

运行配置继续使用后端的 `AI_IMPORT_ENABLED`、`AI_IMPORT_WORKER_ENABLED`、`AI_IMPORT_CONCURRENCY`、`AI_IMPORT_TASK_TIMEOUT_SECONDS`、`DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL`、`DASHSCOPE_MODEL`、`DASHSCOPE_REVIEW_MODEL` 和 `CONFIG_ENCRYPTION_KEY`。默认提取、复核均为 `qwen3.8-flash`。密钥不能放入前端或Git；参见 [环境示例](../../server/.env.example) 和 [实现说明](../../docs/AI_IMPORT_RESILIENCE.md)。

## 部署与回滚

Linux包为现有ECS站点的amd64升级包，携带程序、网页、APK、全部迁移、77份真实地图边界快照、公安备案图标及配置示例。PDF处理依赖Poppler，视频处理沿用ffmpeg；现场已做依赖检查。升级控制器依赖本站已保留的上一版部署工具，不是全新服务器安装脚本。

从源码重新打包时，须复用已验收Linux包的 `map-demo` 目录并校验SHA，配置正式 `MAP_DEMO_DIR` 和生产API路径。仅打开开发预览开关不构成地图验收，缺少边界资源不能标为交付通过。

上线前在开发机生成并验证加密SQL和环境备份，不在ECS或OSS生成全量备份压缩包。隔离候选关闭复制的生产队列和短信，生产媒体只读回退；正式切换前等待活动AI任务结束，校验业务数量和原有受保护文件，再切换程序目录并执行迁移。地图必须通过真实生产代理路径的全国→河北→邢台→宁晋、统计、五档屏宽和失败重试验收。

普通回滚关闭AI入口和worker，切回已保留的上一程序、网页及APK下载目录，保留Schema40、企业产品、草稿、批次、原件和OSS数据。已在隔离库验证旧程序可以启动并保留AI草稿；回退期间不使用旧程序恢复Schema40备份。不能自动恢复旧数据库覆盖升级后的业务数据。

[降级SQL](../../deploy/linux/rollback-ai-import-040.sql)只用于停止worker并完成导出核验后的显式删表降级，正常程序回滚不执行。历史公开产品的整理操作使用 `exhibition ai-copy-cleanup --dry-run/--apply`；它保留公开版本，遇到已有编辑或待审草稿则跳过。

现场控制器 [upgrade-ai-import-040.py](../../deploy/linux/upgrade-ai-import-040.py) 按检查点执行：`stage 包路径 SHA256` → `candidate` → 外部验收 → `stop` → `approve-candidate 网站地图JSON APP地图JSON API验证JSON` → `promote 网站地图JSON` → `verify`。备份须先在开发机验证，验收JSON须来自实际访问结果。已上线站点不要重新执行stage；需要回退时，先停止接收AI任务并等待活动任务结束，再执行 `rollback`，脚本仅回退程序并保留Schema40及业务数据。

本次正式网站与APP内置页面均通过全国→河北→邢台→宁晋、五档屏宽及故障重试检查；88号产品在桌面、手机均不再显示来源列或PDF页码。APP已从正式HTTPS地址完整下载并核对SHA256。87、88号产品分别生成私有整理草稿101、100，原公开版本97、99保持不变。
