# 中企展馆 Flutter App

当前 Android 版本 **1.5.19+27**。本轮优化厂商工作台、我的、产品与展厅管理和推广，保留地域地标首页、展馆切换及普通浏览功能，沿用原工程、包名和签名。厂商端说明与测试见 [交付记录](../docs/MERCHANT_UI_1.5.19.md)。

首页取消全部分类网格和标签，使用后台原始地标图作为宣传横幅，之后直接展示推荐厂家。分类筛选保留在厂家和产品列表。首页只显示接口返回的前六家推荐厂家、前六个精选产品，支持下拉刷新。

顶部“中企展馆”和展馆下拉框同一行展示，默认农业机械馆；电线电缆馆是明确标注“筹备中”的前端扩展示例，不创建后端展馆、分类或企业数据。该示例的首页、厂家及产品页只显示筹备状态，不查询农业业务数据。会话内保留展馆选择，重新启动默认农业机械馆；切回时恢复原筛选与浏览位置。收藏和厂商工作台从“我的”进入，属于全局账号功能。

默认 API 为 `http://39.97.250.244:8089`，已有自定义地址继续保留。地址设置位于“我的 → 设置”。切换地址会退出登录，本地草稿和收藏继续按原服务器、原账号隔离。

从项目根目录加载 `scripts/flutter-env.ps1`，进入 `mobile` 执行：

```powershell
& $taskFlutter analyze --no-pub
& $taskFlutter test --no-pub --concurrency=1
& $taskFlutter build apk --debug --no-pub
& $taskFlutter build apk --release --no-pub
```

仅需本地构建时直接使用 Flutter 命令；`scripts/build-apk.ps1` 还会更新多个网站下载副本，本轮未执行该发布脚本。

签名密钥保存在 `.local/signing`，不加入交付包。Release 沿用原签名，不创建替代密钥。Debug 使用开发签名，与原 Release 签名不同，不能直接覆盖生产安装；保留正式安装及其数据进行验收。

上轮地标首页、截图和验证限制见 [地标首页与展馆切换交付记录](../docs/LANDMARK_HOME_1.5.18.md)。上一轮说明保留在 [首页升级交付记录](../docs/HOME_UPGRADE_1.5.17.md)。原收藏同步和安装说明见 [Android 同步说明](../docs/ANDROID_SYNC.md)。
