当前 Android 验收版本 **1.8.1+36**，应用名称为“大陆农机”，沿用原包名和发布签名。表单改为外置标签，产品与厂家使用紧凑卡片和底部筛选抽屉，采购中心采用移动交互，企业展厅切换六栏目时上部保持稳定。[本轮修改、截图与验收](../docs/MOBILE_UI_UX_1.8.1.md)。历史采购集成说明见 [Android 1.8.0 交付记录](../docs/ANDROID_1.8.0.md)。历史厂商端说明见 [1.5.19 交付记录](../docs/MERCHANT_UI_1.5.19.md)。

采购和商机复用本次构建时打包的最新 React 页面，在应用内工作台运行，与原生端共用服务器和业务账号。首页采购入口在登录前后均进入大厅；发布需求、我的询价和消息从大厅进入，采购商资料位于“我的”。内嵌网页移除重复工作台顶栏与侧栏，保留原生返回及语言切换。厂商商机仍在厂商工作台。私有附件使用业务鉴权，支持应用内图片/PDF 预览和系统保存；Office 仅下载。WebView、系统文件选择器及真机安装须在设备上补验。

采购入口先检查 `/api/v1/public/config` 的 `capabilities.procurement`。当前默认服务器仍未返回该能力，应用会提示更新配套服务；仅安装 APK 不会启用旧后端缺少的采购接口。应用不包含测试账号、万能验证码或服务端密钥。

首页取消全部分类网格和标签，使用后台原始地标图作为宣传横幅，之后直接展示推荐厂家。分类筛选保留在厂家和产品列表。首页只显示接口返回的前六家推荐厂家、前六个精选产品，支持下拉刷新。

顶部“中企展馆”和展馆下拉框同一行展示，默认农业机械馆；电线电缆馆是明确标注“筹备中”的前端扩展示例，不创建后端展馆、分类或企业数据。该示例的首页、厂家及产品页只显示筹备状态，不查询农业业务数据。会话内保留展馆选择，重新启动默认农业机械馆；切回时恢复原筛选与浏览位置。收藏和厂商工作台从“我的”进入，属于全局账号功能。

默认 API 为 `http://39.97.250.244:8089`，已有自定义地址继续保留。地址设置位于“我的 → 设置”。切换地址会退出登录，本地草稿和收藏继续按原服务器、原账号隔离。

从项目根目录加载 `scripts/flutter-env.ps1`，进入 `mobile` 执行：

```powershell
& $taskFlutter analyze --no-pub
& $taskFlutter test --no-pub --concurrency=1
& $taskFlutter build apk --debug --no-pub
& $taskFlutter build apk --release --no-pub
```

推荐从项目根目录构建独立交付包：

```powershell
./scripts/build-apk.ps1 -BuildOnly -ApiBaseUrl 'http://39.97.250.244:8089'
node --test scripts/android-workspace.test.cjs
```

`-BuildOnly` 先检查 Web 类型并构建内置页面，再生成签名 APK 和校验清单到 `delivery/android-v1.8.1/`，保留网站现有下载副本。原有不带该开关的发布模式会更新网站下载文件，应在确认发布时使用。只执行 Flutter 构建不会重新生成内置 Web 资源，不能用于本版本的完整交付。

签名密钥保存在 `.local/signing`，不加入交付包。Release 沿用原签名，不创建替代密钥。Debug 使用开发签名，与原 Release 签名不同，不能直接覆盖生产安装；保留正式安装及其数据进行验收。
