## 原因与修复

页面为管理员“系统设置→上传与容量”，全局厂商容量额度300MB本身在允许范围。`PUT /api/v1/admin/settings`在事务中保存设置，并将修改前后完整JSON写入`operation_logs.note`。原字段`VARCHAR(1000)`不足以容纳当前配置；严格MySQL模式报1406，导致设置和审计日志同时回滚，前端显示“服务暂时异常，请稍后重试”。这不是企业资料提交接口的问题，也不是MB单位换算或300MB超限。

038迁移仅将审计日志note扩展为TEXT，保存完整修改记录，不截断既有日志。不修改额度单位、权限、版本冲突校验、实际配置数值、企业产品内容或AI识别逻辑。页面及API无需调整。
