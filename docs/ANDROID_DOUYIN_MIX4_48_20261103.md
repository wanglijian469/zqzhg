# 小米MIX4抖音加载失败：48版修正与诊断

用户在47版原签名候选包上反馈：小米MIX4所有抖音视频均显示加载失败，包括7136314708138724640；点击“打开抖音原视频”可以播放。此反馈证明47版手机验收未通过，不能晋级正式下载。它将问题范围缩小到App内的官方播放器加载链路，但尚不能区分最终的网络、证书、WebView组件或资源失败原因。

## 已证实的代码问题及改动

- 原代码在主文档未完成加载20秒后调用 `fail()`，直接销毁仍在加载的WebView。48版只提示“加载较慢”，保留原播放器继续等待；不自动重试。手动重试、关闭或离开仍释放旧实例。
- 原 `onReceivedSslError` 对任何附属资源一律销毁整个播放器。48版继续取消所有证书错误，只有官方播放器文档、核心脚本及核心接口失败才关闭；附属图片或监测请求的证书错误只保留脱敏诊断，不再直接关掉整个播放器。
- 区分域名解析失败、超时、安全连接、HTTP错误、无效地址、渲染进程退出及慢加载。新增可展开、可复制的“播放诊断”，包含手机型号、Android版本、真实App版本与版本码、WebView组件版本、错误分类、服务主机名及错误编号。没有Cookie、登录令牌、原始分享内容、签名媒体地址或完整查询参数，不自动上传。
- 新的加载会话隔离旧回调；慢加载后仍能接收完成通知，停止后旧回调不能恢复会话。每次打开或手动重试才建立新会话，无循环刷新。

HTTPS、资源名单、受限iframe、用户手势、文件访问禁止及外部导航限制保持；没有忽略证书，没有修改UA或放开第三方Cookie。二维码、产品、协议、审核、配额和后端不变。抖音仍通过官方按钮播放，不承诺自动起播。

相关官方依据：[WebViewClient错误回调](https://developer.android.com/reference/android/webkit/WebViewClient)、[抖音官方IFrame接口](https://partner.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/video-management/douyin/iframe-player/get-iframe-by-video)。Android文档明确附属资源也会进入错误回调；证书错误应取消，不能继续加载。
