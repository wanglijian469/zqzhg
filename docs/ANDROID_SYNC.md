# 大陆农机 Android App 1.5.16+24

本次增加访客收藏、普通访客账号及登录同步；底部顺序改为“看厂家、找产品、收藏、我的展位”。启动仍显示展馆首页，主页面通过左上角首页图标返回。功能、接口、截图及后端升级步骤见 [收藏说明](FAVORITES.md)。

## 安装与连接

安装 `delivery/android/dalunongji-1.5.16+24.apk`，包名 `com.zqzt.dalunongji`，版本码 24，沿用原 Release 签名。最低 Android 7.0（API 24），包含 ARM、ARM64 和 x64。

已有旧版时直接覆盖安装，保留应用数据；不要先卸载或清除数据，以便保留本机草稿和未同步收藏。本机未连接 Android 设备，真机全新安装及覆盖升级尚未实测。

默认连接 `http://39.97.250.244:8089`，已有自定义地址继续保留。更换服务器会退出登录，草稿和收藏按服务器地址分别保存。

## 收藏与同步

- 未登录即可收藏厂商、产品；列表与详情页按钮状态联动，本机记录在重启后恢复。
- 收藏页分厂商和产品两个标签，支持打开详情与取消收藏；内容下架保留“暂不可用”条目。
- 普通用户可注册访客账号，无需建展位；已有厂商选择厂商账号登录。登录后自动合并当前访客收藏并去重。
- 本机队列在服务器确认后才清理；离线、请求失败、丢失响应和账号切换不会丢失原账号队列或误传到另一账号。
- 账号菜单支持退出；退出后显示剩余访客收藏。访客账号没有厂商管理权限。

跨设备登录同步需要先升级配套 1.5.16 后端。旧服务器仍可使用 App 本机收藏，并显示同步服务升级提示。本次未发布线上。
