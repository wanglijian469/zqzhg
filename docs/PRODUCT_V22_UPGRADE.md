# 中企展馆 V2.2 产品提交页交付记录

日期：2026-10-18。本轮在原React／TypeScript／Go项目完成厂商产品新增、编辑的三步骤改版，P0、P1均已实现。Android、全站公开页面和管理员工作布局未改版；生产服务器未部署。

## P0：基础发布与兼容

- 厂商产品新增显示“发布产品”，编辑显示“编辑产品”。基础信息→图片与展示资料→预览并提交；步骤切换不创建服务器记录，用户明确保存／提交才写入。
- 产品名称唯一必填，最多200个Unicode字符。分类、关键词、图片、说明、参数及英文资料均选填。前后端已同时移除“分类或关键词至少一项”；管理员代录和编辑共用新校验。
- 分类使用当前企业真实所属展馆，最多6个已启用正式分类快捷选项；新增分类折叠为次级入口，原分类建议与别名功能保留。
- 英文、关键词和补充资料默认折叠；旧产品原文、图片顺序与英文完整回填。预览关联当前账号真实企业，不向名称拼接企业名。提交审核、公开版本和待审核只读规则保留。
- 短提示与浅灰占位区分，计数仅聚焦／接近限制／错误时显示；字段错误自动定位所属步骤并展开对应区域。
- 手机单列，44px以上主要操作，底部操作区按实际高度预留空间和安全区。VisualViewport检测键盘缩小视口后将操作区移回正常文档流，输入字段预留滚动距离。

## P1：建议、参数、草稿和图片

- 名称、已有型号与真实分类生成去重关键词建议；中性产品说明不声称性能、认证或应用场景。先显示建议，点击后添加，不自动覆盖已有内容，也不自动写入英文资料。
- 参数保持原文本字段，一键追加当前展馆空白模板。农业机械包含型号／动力／幅宽／尺寸／重量；电缆包含型号／规格／额定电压／导体截面积；未知展馆使用通用模板。不插入数值、不解析重写旧原文。
- 本机草稿按账号与产品隔离，兼容旧缓存并记录步骤、云端产品和版本。每步可以保存云端草稿，保存后留在原步骤；首次创建结果立即缓存，刷新、提交失败及重试继续同一产品。
- 保存／提交单请求锁避免重复点击；失败保留文字和已上传图片。返回管理等站内链接提醒未同步内容，刷新／关闭使用浏览器离开提醒。浏览器后退仍依赖文字自动草稿恢复，没有新增全站路由拦截器。
- 图片复用原接口及XHR进度：本地预览、失败重试、替换、移除、封面、拖动和前后移动。首张为封面，最多12张、每张10 MiB，JPEG／PNG／WebP。待上传文件未解决时阻止保存；替换／移除仅调整引用，不删除上传资料。
- 相册与拍照入口分开，拍照通过浏览器capture提示提供；浏览器是否支持相机入口由设备决定。文件选择无法跨刷新保留，文字草稿会说明重新选择。
- 视频／画册管理保留在次级区域，使用原组件，置于产品表单外避免嵌套form。

## 与入驻页的统一方式

复用现有按钮和表单基础样式、分类选择与补充分类、字段长度规范、校验错误文案、确认弹窗、图片上传和国际化合并方式。产品界面独立分步，不再注入原FormGuide的大段样例和计数；企业入驻流程及其必填规则不改动。样式以product-editor为范围，不改变公开页面布局。

## 新旧规则及接口

| 项目 | 原规则 | V2.2 |
| --- | --- | --- |
| 名称 | 必填，最多200个Unicode字符 | 保留，名称可仅产品名＋型号 |
| 分类／关键词 | 至少一项 | 均选填；填写分类时仍验证有效性与所属展馆 |
| 图片 | 可选，最多12张 | 保留，增加顺序、封面及队列体验 |
| 英文 | 可选 | 保留，折叠且不自动翻译 |
| 参数 | 文本 | 原字段保存＋空白模板，原文不重写 |
| 草稿保存 | 创建后新产品通常返回列表 | 留在当前步骤，缓存云端ID与版本，继续更新同一产品 |
| 公开 | 管理员审核后公开 | 保留，保存不等于公开 |

没有新增业务API、字段、表或迁移。继续使用POST /merchant/contents、PUT /merchant/contents/:id/draft、POST /merchant/contents/:id/submit和POST /merchant/media，均位于/api/v1下；OpenAPI补充新的可选规则。权限、图片所有权、产品配额、审核和分类归属检查保留。

- 前端npm test：21个文件、120项通过，包含8项新增产品编辑器测试；npm run build（含TypeScript）通过。项目没有独立lint脚本。
- 后端隔离MySQL 5.7.18：非视频全套66项业务测试通过，视频另1项通过；V2.2浏览器隔离夹具另1项通过；go vet通过。业务测试合计67项，夹具不混入业务计数。
- 本轮按上一轮已验证的分组方式执行Go测试，未声称普通单条go test -v ./...完整结束。真实OSS缺少隔离凭据跳过；旧手动浏览器夹具没有启用。
- 浏览器Edge无头：1440、1280、768、390、360px，中英文，100%／125%等效CSS视口，三步骤共60组布局通过；7组交互检查通过。检查真实鉴权上传、失败保留和重试、保存阻断、同产品续编、重复点击、图片排序、旧参数／英文和离开取消；无新增页面脚本错误。
- 浏览器交互及截图全部来自自动删除的独立测试库；截图中企业、产品与几何图片为明确标注的测试资料，不写入业务库。统计POST仅在验收浏览器上下文拦截。
- 本机业务库没有测试写入。更新前后核对的公开数据为6家企业、41款产品；APK版本1.7.0+29及字节保持不变。旧交付包继续保留。
- 前端既有大分包体积提示仍存在，本轮无新增大型依赖。

## 未验证与限制

P0、P1功能无已知未实现项，以下范围不计为通过：

- 无iOS／Android真机，真实拍照、相册权限、系统软键盘与安全区未验收；125%为等效视口，不是手动操作浏览器缩放。
- MySQL8、真实OSS和Linux运行环境未验证；Linux程序为交叉编译产物。
- 网络中断发生在首次创建已落库但浏览器未收到响应的瞬间，原API没有幂等键；本轮单请求锁解决重复点击，不能承诺这种断网情形的严格一次创建。不会自动重试首次POST。
- 浏览器后退未增加全站阻断，依靠账号隔离的自动文字草稿恢复；待上传文件需要重新选择。localStorage不可用会提示先保存云端。

## 命令、部署和回滚

本地更新：

~~~powershell
. ./scripts/go-env.ps1
cd web
npm test
npm run build
cd ..
./scripts/stop.ps1
./scripts/start.ps1
~~~

后端测试：设置RUN_MYSQL_TESTS=1，在server依次执行：

~~~powershell
go test -v -count=1 -skip '^TestVideoWorkerProcessingRetryAndRecovery$' ./...
go test -v -count=1 -run '^TestVideoWorkerProcessingRetryAndRecovery$' .
go vet ./...
~~~

浏览器验收：先设置RUN_MYSQL_TESTS=1、V22_BROWSER_HARNESS=1，启动go test -v -count=1 -timeout 14m -run '^TestProductV22BrowserHarness$' .；待.local/v22-browser-fixture.json生成后，在根目录运行node scripts/verify-product-v22.cjs。测试令牌文件随夹具结束删除，不分发。

生产未部署。先备份当前数据库、媒体、环境和整套程序／dist，再配套替换新程序与完整dist；没有新迁移。保留生产环境PUBLIC_BASE_URL、媒体、FFmpeg和进程管理配置，不覆盖签名、APK运营数据或.env。检查/api/v1/health、登录、仅名称草稿、提交审核及公开显示。

回滚恢复部署前配套程序和dist，不删除产品数据。旧版再次编辑“无分类且无关键词”的新产品时，可能要求补填其中一项；回滚前需评估或使用支持新校验的兼容后端。本机旧程序和本轮原始文件保存在.local/backups/pre-v22-product，不纳入交付包。
