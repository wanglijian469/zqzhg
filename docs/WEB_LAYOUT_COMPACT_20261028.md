# 首页与检索页布局精简

2026-10-28，根据用户截图调整本机网站。

- `/` 直接展示农业机械厅，暂时隐藏独立的行业展厅总页。展厅切换菜单和筹备状态继续使用，独立总页组件保留供以后展厅增加时启用。
- “找厂家”“找产品”移除 `ZQZG / EXPLORE THE EXHIBITION` 装饰文字，缩小标题区及筛选栏上方间距，保留检索、筛选、分类和分页。
- 面包屑单独限定样式，避免继承全局导航的大幅上下内边距，以及手机端的绝对定位。列表页桌面端保留紧凑面包屑，手机端隐藏该行。
- 厂商地图及首页不再渲染面包屑；地图继续使用现有边界、下钻、统计及资源重试实现。
- 首页与 `/?hall=agriculture` 对应同一内容，规范地址统一为 `/`，站点地图不重复输出。

TypeScript 构建、31项相关网页回归及后端首页／站点地图／采购停用相关测试通过。隔离数据库浏览器验证覆盖360、390、768、1440px及中英文，共32种页面组合，检查首页、厂家检索、产品检索和厂商地图的实际布局。1440px下筛选栏顶部从383px收紧到216px，桌面面包屑高度从113px收紧到34px。结果见 `docs/test-output/compact-layout-20261028.json`，截图见 `docs/screenshots/compact-layout-20261028/`。地图截图只用于布局验收，不代表部署边界资源验收。

复验命令：加载 `scripts/go-env.ps1`，设置 `RUN_MYSQL_TESTS=1`、`CIAME_BROWSER=1`、`CIAME_COMPACT_LAYOUT=1`，在 `server` 运行 `go test -count=1 -timeout 4m -run '^TestCIAMEBrowserAcceptance$' -v .`。

本次更新本机网页与配套首页SEO，不生成部署包或覆盖已交付的 Android 1.9.0+37 安装包。此前 Android 发布校验报告对应其构建时的网页快照。
