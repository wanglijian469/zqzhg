# 厂商后台账号登录

冀农公司的登录入口：<http://localhost:8080/merchant/login>，选择“已有公司账号登录”。账号为 `河北冀农农机具有限公司`，本机初始密码保存在忽略版本控制的 `.local/accounts/V0001.json`，并已交给用户；本文和交付源码包不包含密码。

账号绑定原 `import:V0001` 的同一账号 ID，保留原展位、19 款产品、全部图片和历史审核记录的所属关系。数据库保存 bcrypt 密码哈希，业务电话继续作为公开联系方式，不作为手机号验证结果。

登录后进入厂商工作台：

1. 点击“展位管理”的“编辑”，修改公司名称、地区、主营、联系方式、介绍和企业图片。
2. 在已有产品行点击“编辑”，修改产品名称、分类、关键词、参数及实拍图片。新增产品使用“添加产品”。
3. “保存云端草稿”暂存；“提交审核”交给平台管理员。审核通过后公开更新，审核期间旧公开版本继续显示。

每个厂商最多 1000 款产品，包含草稿及下架记录。账号权限只覆盖本厂商内容。网站导航新增“厂商后台”，原短信验证码登录保留。

## 管理员配置

后端启动自动应用 `002_merchant_login.sql`，为账号表增加可空且唯一的 `login_name`；厂商登录接口为 `POST /api/v1/auth/merchant`。用户名和密码登录有每 IP 每分钟 10 次限制，错误响应不区分不存在账号和错误密码。

以下本机命令为已导入厂商配置或重置登录。必须由掌握服务器运行环境的管理员执行，密码在 12–72 字节之间；重置会撤销该厂商所有旧会话，保留账号及资料归属。

```powershell
cd server
$env:MERCHANT_LOGIN_NAME = '河北冀农农机具有限公司'
$env:MERCHANT_LOGIN_PASSWORD = Read-Host '厂商密码' -MaskInput
./exhibition.exe set-merchant-login V0001
Remove-Item Env:MERCHANT_LOGIN_PASSWORD
Remove-Item Env:MERCHANT_LOGIN_NAME
```

## 管理后台重置密码（1.5.3）

已有公司账号丢失密码时，管理员可从“厂商账号”列表或厂商详情点击“重置密码”，随机生成或手动设置后交给厂商。账号名称与原展位、产品和图片归属保留，旧会话撤销；无公司登录名的账号不开放此功能。详见 [PASSWORD_RESET.md](PASSWORD_RESET.md)。

## 1.5.5 自行注册入驻

新厂商从 `/join` 填写企业资料，点击“注册／登录并保存草稿”或“注册／登录并提交审核”，设置公司登录账号和密码即可继续，无需短信。已有管理员代录账号选择“已有公司账号登录”；已有展位只允许进入原资料管理。完整异常处理与步骤见 [REGISTRATION.md](REGISTRATION.md)。
