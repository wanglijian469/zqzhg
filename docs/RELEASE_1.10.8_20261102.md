## 本次功能与兼容

Web 恢复展厅、产品、管理和编辑预览的视频弹窗。本地视频打开后尝试有声起播，失败保留明确按钮，不循环重试；关闭释放、恢复入口焦点，全屏 Esc 先退出全屏。弹窗移出编辑表单，关闭不触发保存。PDF、画册和其他入口保持。

App 保留本轮产品三阶段编辑、图片网格、草稿恢复、复制产品、企业分栏管理及协议确认简化，视频恢复专用窗口并保留输入稳定性修复。此前找厂家视觉优化、页脚、搜索、案例和地图保留。

Schema30 仅新增 `content_create_requests` 表，实现按账号及创建请求编号去重。旧客户端可不传该编号；草稿允许后补资料，新产品提交需名称、末级分类及图片。既有公开和已待审版本不追溯下架；审核、权限、配额、媒体及协议审计记录保留。

主要源码及全部文件差异见提交 `08dfcf3`、`af69386`；核心文件为 `mobile/lib/merchant_form_flow.dart`、`main.dart`、`onboarding.dart`、`taxonomy.dart`、`resources_experience.dart`、`video_links.dart`，Android 的 `OfficialVideoView.kt`、`VideoPlayerActivity.kt`，Web 的 `resources.tsx`、`video-playback.tsx`、`local-video.tsx`、`product-editor.tsx`，以及服务端的 `content.go`、`content_create_requests.go`、迁移030。发布工具为 `scripts/package-appflow-release.py`、`deploy/linux/upgrade-video-1.10.8.py`。
