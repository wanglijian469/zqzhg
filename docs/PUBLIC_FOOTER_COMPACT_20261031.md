# 公共 Footer 二次优化

本机预览：<http://localhost:8080/>。本次直接修改现有组件和样式，已构建生效，未部署线上。

## 调整内容

- 保留深蓝色和三栏结构，两组服务链接改为横向排列、空间不足时自动换行。
- PC 整体上内边距 22px、下内边距 14px；去除桌面链接原先的最小高度及重复留白，标题与链接间隔仍为 8px。
- 主体与版权区之间只有一条细分隔线；版权和备案在左，用户协议、隐私政策、企业展厅服务协议和管理后台在右。
- 平台声明移到下方单独一行；公共 Footer 中删除“技术支持：河北企元数智科技有限公司”。
- 标题仍为 16px、服务链接仍为 15px，品牌和法律文字字号均未缩小。
- 手机端不固定高度，链接自然换行；保留必要的 44px 触控区域。地图、注册登录的专用页脚与厂商独立展厅保持原样。
