# 看厂家：统一封面与品牌卡片（网站1.5.9）

“看厂家”每行一家企业：宽幅封面、Logo、企业名称、主营、地区、进入展厅和联系厂家。桌面1200px以上三块并排，768–1199px展品区域在下方，手机上下排列。产品图片完整展示，没有购物、价格或促销功能。

## 配图与管理

后台进入“厂商管理”，点击目标企业的 **设置封面**，会打开原企业资料编辑页、展开宣传资料并定位到品牌图片区。可以上传／替换／移除企业Logo和展台封面，或从本企业已有图片中选择。厂商自行编辑也提供同样的用途说明和草稿卡片预览。

封面统一用于厂家列表、首页品牌展厅、企业展厅。读取顺序为 `company_profile.cover_media_id → media_ids[0] → 工业风占位`；已设置封面但获取或解码失败时直接显示占位，不改用其他图片。Logo完整展示，封面适度裁切，建议16:9，JPEG／PNG／WebP且每张最多10 MiB。

上传失败保留文件并提供重试，未成功上传时阻止保存；保存草稿不会公开。待审期间禁止修改封面，列表快捷入口显示原因。提交审核并通过后，新封面公开；修改草稿及待审期间继续使用旧公开封面。后台与厂商页面的“厂家列表卡片预览（草稿）”只展示当前输入，不执行跳转、不包含未审核产品。

## 展品与导航

复用公开列表原 `matching_products`，最多展示3款，产品缩略图保持4:3完整展示。关键词或分类筛选时标为“匹配展品”，无此筛选时标为“展品速览”；地区筛选不会改变这一名称。没有产品时分别显示“暂无匹配展品，可进入展厅查看”或“暂无公开展品”，不以3款预览代替全部产品数量。

企业入口使用规范 `/v/别名` 或 `/v/v-ID`，联系按钮打开现有联系我们栏目。进入企业、产品及联系栏目后，返回保留厂家列表的关键词、分类、地区、页码和每页数量。
