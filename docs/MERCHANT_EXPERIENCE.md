# 网站与 Android App V1.4.9

首页首屏、顶部导航、入驻页和页脚均可进入 `/app`。Android 卡片提供 APK 和下载二维码；iOS 标记“即将上线”，使用手机网页版进入 `/join`。本版没有 iOS 安装包，也没有公网部署。

## 厂商日常操作

网站进入 `/merchant/login`，App 进入厂商入口；已有公司账号选择“账号密码登录”，新厂商仍可使用短信验证。登录后四项菜单分别是工作台、展位管理、产品管理、展台推广。网站电脑端为左侧菜单，手机网站为顶部标签，Android 1.5.15+23 起为顶部可滚动标签，1.5.16+24 起底部固定为看厂家、找产品、收藏、我的展位。退出登录位于右上角账号菜单并需确认。[新版布局](APP_NAVIGATION.md)。

工作台显示全账号产品总数、已公开、待审核、已驳回和草稿数量。审核状态与是否公开分别显示；产品审核通过，但展位尚未公开时，产品仍不能公开访问。

展位管理编辑企业基本资料、联系方式、介绍、图片和宣传资料，英文资料默认折叠。Android 可编辑宣传简介、企业实力、封面、Logo 和区域联系人；未编辑字段保留。产品管理可按关键词、审核状态、公开状态筛选，每页 20 条；返回编辑前的列表时保留条件和页码。“更多”里有审核记录和下架操作。

离开编辑页面会保留本机草稿；“保存云端草稿”同步到服务器，“提交审核”提交当前资料。待审内容冻结。修改待审时原有公开版继续展示；驳回原因在管理页面显示。草稿按服务器、账号及内容隔离，修改服务器地址会退出登录。

## 展台分享

展台推广只读取已公开资料和规范展台地址。国内展示微信好友、朋友圈、QQ、QQ空间、企业微信、钉钉；海外折叠展示 WhatsApp、Telegram、邮件。

微信好友、企业微信、钉钉和 WhatsApp 使用复制文案、链接或发送海报的指引；朋友圈优先保存海报。QQ、QQ空间和 Telegram 提供网页入口，邮件预填标题和正文。打开平台页面不代表已发送。网页系统分享仅在浏览器支持时显示，取消不报错。未接入微信公众号 JS-SDK。

Android 本地生成二维码和海报；“下载二维码 / 下载宣传海报”打开系统文件保存位置选择器，“系统分享 / 分享海报”打开系统分享面板，由用户选择接收应用。没有新增相册读取权限。分享失败可重试，也可复制链接手动发送。

## 本机与手机访问

本次打包默认服务地址为 `http://172.27.35.2:8080`（2026-10-12 本机 WLAN 地址）。手机需要与电脑同网，打开 `http://172.27.35.2:8080/app` 下载新版；已有 App 可直接覆盖安装，保留原签名及本机设置。已有 App 若保存了旧服务地址，请在设置中改为当前地址。

本机 `.env` 的 `APP_DOWNLOAD_BASE_URL` 用于下载二维码，`PUBLIC_BASE_URL` 用于展台规范地址；目前均为上述局域网地址。电脑 IP 改变后更新这两个值并重启服务；App 设置也要更新。localhost 二维码不提供给手机扫描。界面明确提示本机地址或局域网地址的访问范围。需要公网使用时再配置正式 HTTPS 域名。

## 接口与验证

`GET /api/v1/merchant/dashboard` 返回 `{products:{total,public,draft,pending,rejected}}`，统计当前账号全部产品。公开计数和列表筛选使用同一公开条件。

`GET /api/v1/merchant/contents` 新增 `q` 与 `public_state=public|unpublished`，可与 `kind/status/page/page_size` 组合，始终限制为当前账号。

`GET /api/v1/public/app` 返回 `android_url/qr_url/base_url/ios_available`，不包含账号、密码或供应商凭据。

验收输出在 `docs/test-output/experience-*`；截图在 `docs/screenshots/experience-*`。业务变更自动测试只使用 `zqzt_exhibition_test_*` 独立库，冀农正式资料只读核对。
