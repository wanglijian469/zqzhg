- 已验证的是空清单、未批准资源拒绝、缓存修复、显式编码映射、合成多面／孔洞渲染及统计浏览。真实全国→省→市→县轮廓的正式验收仍未完成。

按用户确认，先交付移动端其它升级的独立验收包。地图页保留真实统计、地区选择及厂商查询，明确提示轮廓尚未开放；不以方块或合成几何冒充完成。

当前结论：**无已核验、可公开发布的行政边界图形资源。本版仅发布行政区划列表模式。** 生产资源清单为空；ECharts 本身的开源许可不涵盖第三方地图数据。

已核实的公开要求参考：

- [《地图管理条例》](https://www.gov.cn/zhengce/zhengceku/2015-12/14/content_10403.htm)：涉及行政区域界线、地图审核、完整疆域表示及审图号标注的要求。
- [《地图审核管理规定》](https://ghzrzyw.beijing.gov.cn/zhengwuxinxi/zcfg/gz/202205/t20220530_2724733.html)：审核范围、公益性地图适用条件及最终公开形式的相关要求。
- [标准地图服务系统](https://bzdt.tianditu.gov.cn/)：可作为公开版地图参考来源；不能将网站可下载视同任意加工／发布授权。
- 交互参考 [河北工厂网](https://hebeigongchang.cn/regions)，仅参考行政区划浏览思路，不复制厂商资料、产业统计或边界数据。

后续每份候选资源须保存以下人工核验材料：

1. 数据提供方、原始下载地址、取得日期、版本、适用区域、许可原文和授权凭据。
2. 原始及最终文件 SHA-256；完整区划编码映射；必要附图及全国疆域完整性检查。
3. 审图材料、有效范围及主管机关可验证出处；确定最终 ECharts 着色、下钻、标签及显示形式的发布要求。
4. 需要另行审核的，保存针对最终成品的审核材料；不能以原始底图审图号替代改变后形式的适用核验。
5. 核验人员、日期、允许公开的具体范围；页面显示的来源、版权／许可要求及审图号。

工具核验通过仅说明材料字段、文件哈希和编码映射一致，不意味着已完成法定审核。完成以上核验后才登记资源；缺失、过期或不适用的资源继续使用列表模式。
