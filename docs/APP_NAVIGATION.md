# App 导航与厂商操作优化（1.5.15+23）

后续 1.5.16+24 已将底部“逛展馆”替换为“收藏”并调整顺序；启动首页保留，最新行为见 [收藏与导航说明](FAVORITES.md)。本页记录 1.5.15 的原始交付。

## 使用方式

App 底部固定为“逛展馆、看厂家、找产品、我的展位”，首次进入逛展馆。四个页面按需加载；切换时保留搜索、分类、地区、页码和滚动位置。首页搜索直接切换到对应的厂家或产品列表并应用新关键词，详情与编辑页返回后恢复原页面。

“看厂家”卡片保留封面、Logo、企业名称、主营、地区、进入品牌展厅和联系入口，取消卡片内整块展品预览。企业展厅、代表展品和独立产品列表仍使用原有公开接口。

“我的展位与产品”使用顶部可横向滚动的四项标签：工作台、展位管理、产品管理、展台推广。退出登录位于右上角“账号”图标菜单，确认后返回登录／入驻入口；取消保持登录。本机草稿继续按服务器和账号隔离，登录其他账号时重建厂商页面。

## 展位管理

顶部显示企业名称、审核状态、公开状态和审核意见。没有展位时显示“创建展位”。下方按任务分组：

- 企业资料：基本资料与联系方式、Logo 与封面、企业介绍与生产能力。
- 展示素材：资质荣誉、企业图集、短视频、电子图册。
- 查看与审核：预览展位、审核记录，以及已公开展位的“查看公开展厅”。

企业资料和图片入口共用原编辑页，并自动展开、定位到相应区域。离开编辑页保留本机草稿，保存云端和提交审核仍需主动操作。待审核资料只读；视频和图册使用各自的独立管理页，关闭后销毁列表和轮询计时器。注册续接、首次创建展位完成后返回同一个“我的展位”入口。

本次只修改 Flutter 界面与导航，无新增后端 API、数据库迁移或第三方依赖。新入口和提示均提供中英文。
