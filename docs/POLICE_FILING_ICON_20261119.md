# 公安备案官方图标补丁（2026-11-19）

用户提供官方备案 HTML 与图标，要求图标在前、备案号在后。本次为网站页脚补丁，后端仍为 v1.12.4／Schema 39，Android 下载仍为 1.12.0+53。

## 实现

- 使用用户原始 PNG，未重绘、未压缩替换，36×40 像素，SHA-256 为 `8dfecad0dfcb3dc584f2c2447943eefb1fd65a058856eb0611e2c56ddc4c1fe1`。公开静态资源为 `/police-beian.png`。
- 首页、公共页面／地图、企业展厅复用 `PoliceRegistration`。图标显示宽 18px、高度按原图比例计算，与备案号文字居中对齐。图标作为装饰图片，避免读屏重复播报备案信息。
- 备案号与链接继续来自管理员网站配置，未硬编码企业资料。正式值为“冀公网安备13052802002070号”，链接 `https://beian.mps.gov.cn/#/query/webSearch?code=13052802002070`，`target="_blank"`、`rel="noopener noreferrer"`。
- 修改网站前端，不修改数据库、OSS 文件映射、模型设置或 APP 安装包。
