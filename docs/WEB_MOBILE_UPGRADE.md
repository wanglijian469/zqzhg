# 网页移动端体验优化交付

日期：2026-10-17。针对当前 React/TypeScript/Vite 网站，优化公开首页、找厂家、找产品、产品详情及企业六栏目。不修改数据库、API、后台业务、厂商工作台或 Android 源码；此前网站版本包和 Android 1.7.0+29 APK 保留。

## 实际调整

- 页头保留品牌、展馆与网页菜单，处理英文长名称；支持点击关闭、Esc、焦点返回和跳转后收起，不新增全站底部四导航。
- 首页继续使用后台单张主视觉，中文展馆标题保持一行，英文自然换行；压缩留白，精选企业卡改为紧凑图文排列。推荐数量及真实业务资料保持不变。
- 厂家查询卡的封面与企业资料并排，进入展厅与联系厂家按钮整行排列，最多展示三件代表产品。产品列表手机两列、平板三列，图片4:3完整显示。
- 查询和企业产品中心的搜索框常驻，手机筛选默认折叠、桌面展开；展示已选条件，支持逐项移除和清空。关键词显式提交才查询，切换筛选保留尚未提交的输入；筛选改变重置第一页，保留展馆与准确后端总数。
- 企业六栏目改为一套横向吸顶标签，直达链接和窗口尺寸变化都会露出当前项。自动定位只滚动标签；保留旧 tab、hash、展厅别名与详情返回参数。
- 企业子栏目保持紧凑企业信息，产品网格防御重复记录。公开产品详情增加手机主图、缩略图及键盘放大查看，管理预览保留原有图片布局。
- 联系栏按实际高度预留底部空间并适配安全区；图片、视频、画册、分享及电话选择弹窗打开时隐藏。软键盘适配使用 VisualViewport，真机效果仍待确认。
- 电话原备注继续显示，拨号 URI 仅使用识别出的号码，多号码可选择，无法识别则提供复制；复制失败提供可选中的原文。
- 新增文案纳入中英文，关键操作至少44px触控区域。平板等效125%视口筛选区、英文页脚和长链接溢出已修正。

## 本地运行

服务已运行时，更新 web/dist 后刷新 http://localhost:8080 即可，无需重启后端。PowerShell 构建与测试：

```powershell
$env:TEMP = (Resolve-Path .tools/tmp).Path
$env:TMP = $env:TEMP
cd web
npm test
npm run build
cd ..
# 后端尚未运行时：
./scripts/start.ps1
```

浏览器检查分别执行 node scripts/verify-web-mobile.cjs、node scripts/verify-web-mobile-interactions.cjs 和 node scripts/verify-web-mobile-pdf.cjs，使用本机8080服务。后两者的故障和 PDF 数据仅在浏览器路由内隔离。
