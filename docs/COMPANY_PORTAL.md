# 企业宣传门户（网站／后端 1.5.11）

企业独立品牌展厅的规范地址保持 `/v/<别名>` 或 `/v/v-编号`，默认进入“展厅首页”。原 `/vendors/编号` 仍可访问。已有 `tab`、搜索、分类、分页和返回来源保留；没有 `tab` 的旧搜索／分页链接仍进入产品目录。访问没有公开内容的产品、视频或图册栏目时返回展厅首页并提示，保留原查询参数。

## 页面与操作

首页按固定顺序显示企业主视觉、概况、代表展品、生产能力、资质荣誉、企业图集、视频／图册摘要和联系入口。代表展品仍由原自动／手动配置决定，最多3款；手动清空不自动补齐。首页图集最多预览6张，各类资质荣誉最多预览4项；完整资料在企业介绍中展示。视频／图册各预览3项，主动点击才打开播放器／阅读器。

只展示已经填写的基本资料和生产能力。没有公开产品、视频、图册时隐藏对应导航；没有生产能力、资质、荣誉或企业图片时隐藏该模块，不生成营销数字或缺资料提示。企业介绍与联系我们始终保留。基本资料桌面双列、手机单列，企业介绍保持段落和换行。企业经营分类显示当前规范分类名称，包括本企业已审核公开资料引用的补充分类。

厂商进入“厂商工作台 → 展位管理 → 编辑企业资料”，管理员进入“厂商管理 → 编辑”，在展开的“企业实力与品牌资料”内维护生产能力、品牌图片、资质荣誉、图集标注和区域联系人。现有企业名称、主营、介绍、联系方式、企业图库仍在原分组填写。

- 资质荣誉选择“企业资质”或“获奖荣誉”，上传图片，填写中文标题，可补充说明和英文资料。支持替换、移除、上移／下移和已有图片选择；证书缩略图和大图完整展示。
- 企业图集先在企业图片区上传，再逐张填写标题、说明和英文资料，并调整顺序。旧图片可继续使用，标题说明选填；移除图片同时移除对应标注。
- 中文标题、英文标题各最多100个 Unicode 字符，说明各最多500个；资质荣誉中文标题必填。图集仍最多12张，资质荣誉合计最多20项，独立计算，Logo与封面不占名额。
- 继续支持 JPEG、PNG、WebP，每张最多10 MiB；上传有本地预览、进度和失败重试，失败文件保留。上传完成前不可保存，管理员创建厂商后才能上传。
- “预览企业门户”显示当前编辑资料，预览不代表已保存或已公开。保存草稿、提交、审核流程与原企业资料一致，待审禁止修改；修改待审时继续显示旧公开内容。

## 数据、权限与兼容

`company_profile.credentials` 为有序数组，每项 `kind: qualification|award`、`media_id`、`title`，选填 `title_en`、`description`、`description_en`。`company_profile.gallery_annotations` 通过 `media_id` 关联图片并保存同样的标注字段；图集顺序始终以 `media_ids` 为准。数据存入原企业资料版本 JSON，无新增数据库表或迁移。

公开展厅响应增加可空的 `business_category: {id,name,name_en}`，不改变原分类树或产品筛选规则。现有内容接口、图库上传接口、审核接口和规范地址保持兼容，详见 `openapi.json`。

旧客户端保存时省略或传null的新增集合保留当前版本资料；明确传 `[]` 才清空。删除图集图片时清理标注。Android 1.5.2+19 会保留未知资料字段，不新增资质和标注编辑页面，也不展示本轮门户首页。

新增资质图片纳入企业版本媒体引用，检查所属账号及图片类型。管理员和所属厂商可带请求头鉴权预览草稿；匿名只允许访问当前已公开版本引用的图片。替换、移除或展位下架后按现有公开权限即时判断。链接不包含登录令牌。
