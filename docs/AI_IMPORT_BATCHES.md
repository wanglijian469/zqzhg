# AI智能建馆 · 独立与分批提交

本轮不增加收费、额度、充值、扣费；仅记录模型实际Token。此前企业资料提交异常和管理员系统设置日志长度问题不在本轮修复范围。

## 厂商操作

菜单位于企业资料正上方。上传后进入“企业资料／产品资料”两个页签；识别100%仅表示解析完成。保留保存草稿，主按钮统一为“确认并提交”，打开本次内容清单，核对完填写必要说明后保存当前编辑、确认版本并提交原平台审核，不会直接公开。

企业可单独提交。已有企业时，不选覆盖字段表示沿用现有资料，不修改原版本；未使用的AI更新建议不阻止产品提交，也不会被后台自动确认。企业已有待审资料时，不能通过AI覆盖待审版本。新企业先提交资料取得企业ID，产品可以随后独立进入审核；公共网页仍要求企业和产品满足原有公开规则。

产品每页5项，可筛选未提交／已提交／失败，选择当前页或逐项选择，不默认全选。固定操作栏显示所选数量。分批提交只锁定对应条目，其他条目可编辑；不再要求提交后先解锁整条任务。翻页保留当前编辑。失败项目可修改后用新批次提交；未修改的未完成批次可在“提交批次记录”重试，刷新后入口仍在。已成功条目保持最终业务ID，不重复创建。

## API

前缀 `/api/v1/merchant/ai-import`。全部校验登录、企业／任务／草稿／媒体归属。

| 方法与路径 | 作用 |
|---|---|
| POST `/tasks/:id/company/submit` | 单独确认并提交企业资料，items必须1项 |
| POST `/tasks/:id/products/submit` | 确认并提交所选产品批次，最多1000项且受普通JSON请求体限制 |
| POST `/tasks/:id/batches/:batch_id/retry` | 按服务器保存的原批次快照恢复未完成项，不能用重试覆盖新版本 |
| GET `/tasks/:id/result` | 增加batches、batch_items、submission_stats；草稿增加active_batch_id和blocking_reasons |

提交JSON为 `idempotency_key,items,agreements`；item包含 `id,version,data?,resolution,selected_fields?,publish_mode?,target_content_id?,target_revision_id?`。Data省略表示使用已保存草稿。服务器先核对版本及归属，再预留条目；每个条目的保存、人工确认、业务提交和最终ID同事务提交。缺主图／分类／来源／说明等条目失败不影响其他条目，响应包含逐项error和fields。改变批次清单或数据必须使用新幂等键；原键不同内容409，重复原请求返回同一批次。

批次状态 pending／submitted／partial_failed／legacy；条目状态 pending／submitted／linked／failed／legacy_pending。linked表示沿用现有企业，没有新建待审核企业版本。任务仍使用原queued／processing／review_pending／failed／completed；completed不等于公开，也不再用于锁住未提交条目。

旧 `/publish`、`/review` 接口保留兼容。035迁移只补充旧清单的历史批次与提交方式，不重放发布，不更改旧草稿版本、确认状态、型号、参数或最终ID。其余旧AI接口保留。

## 模型、协议和统计

管理员设置分别选择提取／复核模型，默认均为flash，可明确选择max并确认费用。商户上传忽略任何客户端model_mode／confirm_max覆盖；实际模型来自管理员配置并写入任务现有extraction_model／review_model快照，重试沿用快照。老任务缺少快照时，按原flash或已明确确认的max策略处理。无自动升级模型，无管理员单任务指定入口。管理员PUT设置增加extraction_model、review_model、confirm_max；返回实际配置并保留脱敏及加密密钥行为。

已登录厂商启动AI或提交企业、产品及相同协议组件的资料时，展示当前协议链接和版本，无单独确认按钮。前端随真实操作提交当前key／version／digest，服务端记录web_use来源。同版本不重复记录；读取页面、普通草稿保存、数据迁移均不生成确认。首次注册的主动勾选及平台管理员原有确认流程不变。

036发布服务文案的新版本，保留已有正文、版本和确认历史；原操作人员编写的内容保留，仅替换交互条款并追加说明。访问统计在无保存选择时默认开启，已保存no不被覆盖；关闭后停止后续发送并清除队列及统计标识，原已发送请求不能撤回。仅现有公开页面进入统计，不增加后台画册、企业草稿或技术参数采集。
