# 厂商独立展厅页脚精简

本次只调整独立展厅页面，所有厂商共用同一实现，包含 `/v/:slug`、默认展厅地址及历史 `/vendors/:id` 入口。本机已构建生效，未更新线上服务器。

页脚保留厂商名称，显示“由中企展馆提供展示服务”，其中“中企展馆”返回平台首页。保留实际配置的 ICP 备案号及工信部官方查询链接，采用 11px 小字；如配置了公安备案，也沿用原官方查询入口。移除平台版权、技术支持、入驻与服务说明、入驻使用指南和投诉申请链接。

“分享官网”在独立展厅的页脚、顶部分享入口和分享面板统一显示为“分享展厅”。通过可选的局部文案参数复用原分享组件，厂商工作台及其他页面的默认文案和分享实现保持原样。复制、二维码、海报及系统分享的原有处理均保留。

平台公共页脚未在本次修改，保留版权、技术支持、备案、服务说明、入驻指南和投诉申请。用户可从展厅的平台来源链接返回主站，再直接进入投诉申请；未删除业务页面或后端接口。

## 文件

- `web/src/showroom.tsx`：独立展厅页脚及本页面的分享文案。
- `web/src/showroom-footer.css`：只作用于独立展厅的低高度布局、弱化备案信息及手机排版。
- `web/src/company-profile.tsx`：分享组件新增可选的页面文案参数，其他调用不传参数时行为不变。
- `web/src/showroom.test.tsx`、`web/src/showroom-footer.test.tsx`：更新展厅分享按钮预期，验证不同入口、备案、分享及主站服务入口。
- `scripts/verify-showroom-footer.cjs`：只读检查本机全部公开展厅、布局、分享和主站页脚。
- `scripts/verify-admission-guide.cjs`：同步新的验收要求，平台页脚保留指南，独立展厅不再要求出现平台服务链接。

## 验证

- TypeScript、Vite 构建通过，`git diff --check` 通过。
- 五个相关测试文件，共 28 项通过。
- 本机现有 11 家公开厂商，分别检查电脑和手机，共 22 个展厅状态全部通过；无内容写入。

- 历史数字地址仍使用同一精简页脚。
- 实测打开分享面板、复制地址、生成二维码、预览海报和下载海报成功。
- 电脑和手机的主站完整页脚及投诉入口通过；指南、服务说明、注册和登录页面仍保留公共指南入口。
- 浏览器异常为 0。没有调整数据库、后端服务或线上配置。
