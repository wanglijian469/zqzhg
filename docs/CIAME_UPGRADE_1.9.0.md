# 中企展馆与大陆农机 1.9.0 升级说明

日期：2026-10-28。本轮更新本机网站、Go 后端和 Flutter App，Android 为 **1.9.0+37**。不部署生产、不替换正式下载、不生成 Linux 部署包。

## 名称与访问

- Android 安装、桌面及应用管理名称为“大陆农机”，包名仍为 `com.zqzt.dalunongji`，使用原发布签名。
- App 内平台为“中企展馆”，农业机械厅标题为“中企展馆-农业机械厅”，与网站一致。
- 本机展馆总页：http://localhost:8080/ 。农业机械厅：http://localhost:8080/?hall=agriculture 。厂商入口：http://localhost:8080/join 。
- APK 保留原默认服务器 `http://39.97.250.244:8089`。本轮没有更新该生产服务器；验收新版分类及审核流程时，应在 App“我的 → 设置”中选择本机配套服务地址。手机访问需使用同一局域网内电脑的 IP，不能填写手机自己的 localhost。

## 展馆和分类

默认进入“展馆总页 → 行业展厅 → 厂商展台／官网”。农业机械厅开放，电线电缆厅保持筹备状态。原厂商、产品和 `/v/:slug` 官网链接继续使用；总页和农业机械厅拥有各自的规范地址及站点地图入口。

分类唯一来源为 `需求文档/CIAME产品类别分类表.xlsx` 的明细：**29 个一级、159 个二级**。附件统计页的 32／179 与明细不一致，本轮按用户确认采用明细，不补造类别。完整基准和附件 SHA-256 保存于 `server/catalog/ciame-2026.json`；可用 `scripts/extract-ciame-catalog.py` 从原附件重新提取。

同一份目录生成厂商、产品两种现有 API 类型投影，每种 188 项，保留各自 ID。厂商一个主营、最多两个兼营，兼营和经营性质折叠为选填；产品选择末级分类。网站和 App 均支持搜索以及一级类别筛选下的二级选择。英文界面保留中文目录原名回退。

Schema22 增量迁移具有事务和完成标记。历史分类与合并链可以唯一对应时自动转换，歧义关联进入后台分类管理的映射列表确认。旧目录保留 ID、原名及引用；新增选择隐藏已停用项，原编辑记录仍可保留自己的历史项。旧筛选链接能映射则转换，不能确定则提示重选，默认行业列表和关键词搜索继续展示原公开资料。

本机迁移前后核对：**11 家厂商、46 款产品、69 个资料版本、182 条媒体记录**一致，原版本正文和媒体路径摘要一致。迁移不批量改写审核快照。

## 厂商自助维护

网站与 App 以公司账号注册／登录为厂商主入口，保留现有手机号渠道。注册后直接完善企业资料；账号已有展台则继续管理原资料。

基础填写集中为企业名称、地区、主营产品、主营分类及电话／微信至少一项。Logo、封面、介绍、实拍、资质、视频、画册和英文资料按需补充。操作为“保存草稿 → 预览官网 → 提交审核”。官网预览复用公开模板的品牌与资料组件，未发布内容明确标识；审核通过后公开，复审期间保留已发布版本。空产品、视频及画册栏目和对应产品操作入口自动隐藏。

保留原有草稿、上传重试、未保存提醒、版本检查和重复提交保护。厂商入口、产品管理、官网分享及公开联系方式保持可用。

## 采购暂停与备案

采购默认关闭，本机配置为 `PROCUREMENT_ENABLED=false`。两端隐藏采购、询报价、洽谈、商机和相关消息入口，网页内的旧链接一并隐藏。旧采购页面直接访问时显示暂停提示；采购 API 返回 `503 / proc_disabled`，后台清理任务不启动。历史采购数据及模块保留，供未来版本恢复。

站点设置增加备案号，默认“**冀ICP备2026047360号-2**”。公开页面、厂商官网、入驻登录、地图及 App 关于卡片均提供工信部备案查询链接；无 JavaScript 的公开正文也保留备案信息。

## 构建及回退

网站构建前加载项目 `scripts/go-env.ps1`，使用项目内临时目录；Android 使用 `scripts/build-apk.ps1 -BuildOnly`。Android 内嵌网页重新生成时清空专用中间目录，并去除 HTTP 预压缩 `.gz` 副本，避免 Android 资源名冲突。

本机升级前备份位于 `.local/backups/pre-ciame-20261028/`，包含 SQL、媒体、环境配置及原服务程序；该目录含私有数据，不进入公开交付。需要回退时，先另外保存升级后新增的业务资料，再恢复配套数据库、媒体及旧服务／网页。不要直接删除 Schema22 分类或映射记录。

本轮只交付本机与 Android 验收产物，不将当前网页产物标为通过地图生产交付。下一次网站／Linux 部署包仍必须满足 `docs/MAP_DEPLOYMENT_REQUIREMENTS.md`，从正式产物经实际代理路径验证开发边界一致性，不以预览开关或方块图替代。
