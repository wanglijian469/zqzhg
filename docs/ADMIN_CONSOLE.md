# 管理员运营工作台（网站1.5.10）

入口：`http://localhost:8080/admin`。登录后默认进入 `/admin/dashboard`。沿用本机原管理员账号；参考站账号不写入本平台。后台与公开网站使用独立布局，桌面可折叠导航，手机使用抽屉。

## 日常操作

1. **新增厂商**：在厂商管理点击“新增厂商”。可创建公司账号，也可搜索、选择尚未建展位的现有厂商账号。填写名称、地区、主营产品、电话或微信。新账号登录名默认采用公司名，可调整；创建成功只显示一次随机初始密码。已有展位的账号在“厂商账号”页面直接进入原展位。
2. **编辑资料**：创建基础草稿后，进入详情点击“编辑草稿”，补充中文、英文、联系方式、参数和图片。图片按目标厂商归属保存；上传失败可在当前编辑页重试。保存草稿不公开，随后单独提交审核。厂商管理的“设置封面”快捷入口直接展开、定位品牌图片区；待审禁止编辑。展台封面用于厂家列表、首页品牌展厅与企业展厅，Logo独立展示；两端编辑均有厂家列表草稿卡片预览。见 [封面说明](VENDOR_CARDS.md)。
3. **添加产品**：从厂商的产品数或详情进入其产品列表，再点击“添加产品”；也可在产品管理里搜索并选择所属厂商。名称必填，分类或关键词至少一个。每厂商最多 1000 款，草稿、待审和下架产品都占用名额。
4. **审核**：厂商审核与产品审核分别处理，默认待审。详情提供“最新草稿 / 提交版本”“当前公开版本”和审核历史。四个管理／审核列表均提供单条审核及勾选批量通过／驳回；全选仅当前页待审内容，批量驳回共同原因必填。确认面板可展开资料和图片，完成后逐条展示结果。详见 [批量审核说明](BATCH_REVIEW.md)。待审版本已冻结，先驳回再编辑重提。管理员可以审核自己代录提交的资料，但保存、提交和通过审核必须分别操作。
5. **下架**：点击下架后需确认；公开访问立即停止。厂商下架时，其产品和关联媒体退出游客公开访问。修改待审期间继续使用原公开版本。
6. **展示配置**：分类有层级、排序、中英文和启用状态，服务端阻止分类循环；地区单独维护。“首页展示”保留 `/admin/featured` 地址，分主视觉配图、企业品牌展厅、精选展品三个标签。平台配图上传后需“保存设置”才公开，支持桌面／手机预览。公开厂商可加入、移出首页并排序，准确显示已选数量／12；较小的排序值优先，旧超限记录不自动删除。精选展品最多8款。未公开产品或所属厂商下架的产品不能新增精选。详见 [首页展示说明](HOME_DISPLAY.md)。
7. **账号、日志、状态**：账号显示登录方式与展位归属，已有公司登录名的厂商可从账号列表或厂商详情页重置密码；支持随机生成和手动设置，成功后只显示一次并撤销旧会话。具体见 [密码重置说明](PASSWORD_RESET.md)。不提供账号删除。操作日志按操作人、对象、动作和时间筛选。系统状态只读展示服务、数据库、媒体和短信配置是否齐全，不显示密钥、不发送短信。

筛选和页码保存在 URL；中英文切换保留当前页面、筛选和表单内容。后台深链接可以刷新。登录失效后重新登录，回到原请求页面。扩展分组默认收起，六个模块只说明用途与启用条件，没有虚构数据或可执行功能。

## 权限与追踪

新增管理接口均位于 `/api/v1/admin`，使用现有管理员认证。账号和厂商草稿事务性创建；业务写入与操作日志同事务。管理员作为操作人记录，内容与图片归属不会转移。保存使用 `revision_id` 校验，管理员与厂商不能覆盖较新的版本，也不能关联其他厂商图片。

迁移 `003_operation_logs.sql` 建立通用日志，并按原审核日志 ID 去重补入历史。原 `review_logs` 和内容历史保留。密码只存 bcrypt 哈希，初始密码仅创建响应返回；账号列表、日志、状态接口不输出密码、哈希、会话或短信凭据。公开网站和移动端接口保持兼容。

本次菜单统一定义在 `web/src/admin.tsx`，中英文文案在 `web/src/admin-messages.ts`。后续启用扩展模块时替换其说明页并添加相应认证接口。

## 验证及交付

自动化业务验收只使用 `zqzt_exhibition_test_*` 独立库。正式冀农资料只做只读核对。详见 [测试记录](TESTING.md)、[API 文档](openapi.json) 与 [部署恢复说明](DEPLOYMENT.md)。Android/iOS 工程及 APK 沿用既有功能。

厂商现有账号通过独立厂商工作台管理资料和最多3款代表展品；平台首页精选仍由管理员控制，彼此独立。代表展品设置操作可在日志中筛选，说明见 [MERCHANT_WORKSPACE.md](MERCHANT_WORKSPACE.md)。
