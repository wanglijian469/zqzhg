# AI智能建馆：提取规则、部分完成与标准产品介绍

本轮网站目标版本1.12.6，Schema40，Android 1.12.1+54。模型仍由管理员配置，默认提取、复核均为qwen3.8-flash，不因失败或文档长度自动升级max。

## 内容与证据

公开详情采用产品简介、特点、应用、型号参数和技术图纸。兼容参数文本不再生成PDF页码；公开组件不显示来源列或图注页码，确定的来源标记仅在呈现时过滤。型号、技术原值和单位不改写，原图不重绘。旧客户端可继续读取原数据结构，证据字段、原件和私有响应保留。后台审核仍显示来源页与核对事项。

仅当兼容文本与结构化参数生成文本在去掉来源标记和空白后相等，公开网页才隐藏重复文本；额外人工补充内容保留。

已有AI产品整理命令：`exhibition ai-copy-cleanup --dry-run`只读扫描；`--apply`使用现有保存草稿服务生成更新草稿，要求已部署Schema40。不覆盖已有草稿或待审版本，不改变原公开版本，不重新创建产品。重复执行跳过已有草稿。报告仅输出业务ID、状态及修改字段，不输出画册、参数正文或密钥。正常上线保留原数据库和OSS文件。

## 管理员规则

系统设置→AI模型配置→内容提取规则，包含目录、企业、产品详情和复核四阶段，每阶段最多6000字节。支持预览校验、版本历史、恢复历史到编辑区后另存新版本。预览不调用模型。规则不能覆盖数据结构、技术原值、来源校验、权限、禁止编造和忽略文档指令等固定约束。

默认版本1为升级前兼容规则，版本2为标准介绍规则。新任务固定当前版本；旧任务默认保持版本1及原模型快照。厂商明确选择最新规则时，只更新所选未完成工作单元，成功结果、人工编辑及已提交产品不重跑。各单元记录实际版本，历史规则不覆盖。

接口前缀`/api/v1`：管理员`GET/PUT /admin/settings/ai-prompts`、`GET .../history`、`POST .../preview`。PUT携带`version`、四阶段`rules`及`note`，版本冲突409；普通厂商403。

## 恢复与提交

Schema40新增提示词版本、工作单元及任务快照/结果版本/重试时间字段，企业产品仍使用现有库。目录页失败时继续其他页面；产品失败时先存私有待补草稿，再继续其他产品。参数和图片复核完成前不会被当作可直接提交成果；可人工补齐并填写核对说明，再经原厂商确认和平台审核。

每工作单元每轮最多3次实际模型请求，传输重试、格式修复和证据修复共享预算。2秒/8秒退避，429尊重最长60秒的Retry-After。等待写入MySQL后释放worker，重启继续检查点；不整本重跑。认证、配置、数据库、空间等整体故障停止继续调用。每次实际调用记用量，缺失用量为未知，不记零。原始响应仅在私有审计库保存，不向厂商API返回。

任务仍使用queued、processing、review_pending、failed、completed，新增recognition_outcome及单位统计。部分完成明确显示可核对、待补、已检查页数和失败单元。已就绪产品可以先分批提交，任务状态和租约不会被提交操作覆盖。已有企业无需先采纳AI企业建议；新企业可单独提交或通过原企业资料流程手动建立。

`POST /merchant/ai-import/tasks/:id/retry`扩展`unit_ids`、`prompt_policy`（original/latest）、`prompt_version_id`。latest必须匹配管理员当前版本。默认只处理未完成项；跨企业任务或单元不可访问。人工修改、删除及已提交产品保护不变。PUT产品草稿可携带`manual_complete:true`和`resolution`，记录人工接管，之后仍执行发布必填项、媒体、来源与审核校验。

摘要GET任务返回`result_version`、`unit_summary`、`active_units`、`coverage`；完整result返回单位列表和草稿。页面正常2.5秒查询轻量摘要，异常退避到30秒，隐藏页面15秒；请求完成后才安排下一次，不交叠取消。仅结果版本变化时刷新完整草稿，兼容没有版本字段的旧服务。后台结果更新若与未保存人工编辑冲突，须明确选择采用后台或保留人工，不静默覆盖。

## 开发、部署及回退

Go测试使用隔离MySQL：`RUN_MYSQL_TESTS=1 go test -run 'TestAI|TestCompleteBackupRestoreAndCutover' .`；执行`go vet ./...`。前端运行新增规则、公开展示、慢轮询、编辑冲突及原AI回归测试，再运行TypeScript和Vite构建。Android同步内置网页，沿用原签名，版本号54；未执行真机项目不得报告为通过。

真实画册在隔离库调用flash验收，不将Mock当成识别结果，不向正式企业库提交样例。逐页核对洋柯10页、派一16页及劳斯耐斯12页；型号数量、独立结构和参数以实际原件为准，不写死解析清单。公开88号产品验收来源文字消失，但后台证据保留。

上线前SQL和环境加密备份只存开发机，保持既有媒体备份，不在ECS或OSS生成全量备份包。旧版首升先等待活动识别任务结束；新worker在模型工作单元边界响应维护暂停，检查点保留。候选和正式路径均验证77项真实边界资源、全国→河北→邢台→宁晋、统计、手机及失败重试，保留开发演示数据署名。

普通回滚先关闭AI新增任务/worker，再切回兼容OSS的上一程序、网页和APK下载配置；保留Schema40、草稿、业务库、OSS文件和新识别结果，不恢复旧数据库。单独的`rollback-ai-import-040.sql`仅用于导出验证并停止worker后的显式破坏性降级，普通升级不执行。
