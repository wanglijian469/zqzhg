# 新厂商注册、保存与提交审核 · 1.5.5

## 使用步骤

1. 打开网站“我要入驻”（`/join`），填写企业名称、地区、主营和联系方式。填写内容会作为本机草稿保留。
2. 点击“注册／登录并保存草稿”或“注册／登录并提交审核”。新厂商默认打开注册弹窗，已有公司账号可切换登录；原短信方式仍保留。
3. 公司登录账号默认带入企业名称，可以改为简称，最多100个 Unicode 字符。密码需为12–72个 UTF-8 字节，两次一致，不能全为空白；空格保留。企业名称超过100字时请缩短登录账号，企业名称完整保留。
4. 注册成功会自动上传尚未成功的图片，然后继续原来的保存或提交，进入厂商工作台显示“已保存草稿”或“已提交，等待审核”。审核通过后才公开。
5. 日后使用设置的公司账号和密码登录网站或现有 Android App，继续管理同一展位、产品和图片。

管理员已经代录企业并建立公司账号的，请选择“已有公司账号登录”，向管理员获取账号密码。遗失密码由管理员在“厂商账号”或厂商详情使用“重置密码”。已有展位的账号不会自动覆盖、合并或认领资料，页面提供进入原展位管理的按钮；电话仍只是企业联系资料。

## 草稿与异常

- 取消注册／登录保留企业文字、分类和当前页图片，清除密码与待继续操作。之后单独注册不会意外执行已取消的提交。
- 新增分类、选择 Logo／封面或企业图片要求认证时，只返回分类或上传操作，不保存整份企业资料。
- 密码只存于当前认证输入组件，不写入草稿或浏览器存储。会话沿用原系统 sessionStorage 机制。
- 认证后本机草稿转到当前账号范围；对应入驻草稿云端成功后才清理。待上传文件保留在当前页面，刷新后需要重新选择未上传文件；文字草稿仍可恢复。
- 图片失败保留文件；点击“重试上传并继续保存／提交”会跳过已成功文件，并使用最新图片编号保存。Logo 和封面保持独立入口，不占企业图库12张限额。
- 账号重名显示在登录账号字段旁，可切换已有账号登录。网络超时不会自动重复注册；可能已建账号时先用刚设置的密码登录继续。
- 保存已成功但提交失败时保留展位 ID 和版本，重试提交不会再次创建展位。

## 接口与安全

`POST /api/v1/auth/merchant/register` 接受 `login_name`、`password`。成功201 `{token,account}`，`Cache-Control: no-store`。角色固定为 merchant，每 IP 每分钟5次。登录名按数据库原唯一规则检查；并发重名只建立一个账号。账号、会话和 `merchant_registered` 日志事务提交，失败回滚。数据库只保存 bcrypt 哈希，注册事务的 SQL 日志关闭；响应和操作日志不含密码或哈希。

字段错误保留 `error.code` 并返回 `error.fields`；详细约定见 [OpenAPI](openapi.json)。复用原账号、会话和操作日志表，无迁移。管理员日志可显示“新厂商注册”。
