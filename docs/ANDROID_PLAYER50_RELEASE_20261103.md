# Android 1.10.9+50：紧凑播放器与宽视频适配

## 页面调整

播放器取消系统大标题，采用52dp深蓝工具栏，只保留44dp关闭按钮、标题“视频播放”和更多按钮。正常加载后隐藏整条说明及进度区域，将空间交给视频。重新加载、打开抖音原视频和播放诊断收进“更多”；仅加载慢或失败时出现简短状态和重试。诊断改为用户主动打开的可滚动对话框，保留复制功能。支持系统安全区域和横竖屏布局。

横视频改为依据实际固定容器宽高缩放，容器隔离内部大画布的溢出影响；不再依赖可能被内容撑大的innerWidth。保留官方播放器逻辑尺寸和原比例，使用ResizeObserver响应容器变化，并明确启用WebView的viewport支持。第一方精确本地页面路由、域名规则、HTTPS、证书拒绝、沙箱、手动播放及关闭释放逻辑延续49版。

本轮主要文件：`VideoPlayerActivity.kt`、`OfficialVideoUiState.java`、`OfficialVideoDocument.java`、`OfficialVideoView.kt`、`AndroidManifest.xml`、播放器独立布局／主题／两个图标，以及`mobile/pubspec.yaml`和相关测试脚本。没有新增数据库迁移、业务接口或网站业务页面改动。
