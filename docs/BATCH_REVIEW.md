# 厂商与产品批量审核 · 网站1.5.7

## 操作步骤

“厂商管理”“产品管理”“厂商审核”“产品审核”四个列表共用批量审核入口。

1. 勾选待审核行，或点击“全选本页待审核”。已通过、驳回及草稿不能勾选。切换筛选或页码后重新选择，选择不跨页。
2. 点击“批量通过”或“批量驳回”。确认面板展示名称、所属厂商或地区、缩略图，可以“展开资料与图片”查看完整提交资料，无需逐条进入详情页。
3. 通过可填共同备注；驳回必须填写适用于全部所选内容的共同原因。备注上限1000个Unicode字符。
4. 点击确认后执行审核，显示进度。结果逐条标明成功或未完成，失败说明会保留在当前面板。

每行另有“通过审核”和“驳回”入口，使用同一确认面板，仅处理该行。查看详情入口保留。

## 权限、版本与异常

复用原 `POST /api/v1/admin/revisions/{id}/review`，浏览器按顺序处理明确选中的提交版本，不新增批量接口或改变审核规则。每条在原事务内审核，管理员权限、版本锁、状态校验、审核记录和操作日志保留。通过仍受父展位公开规则约束；修改驳回或待审期间原公开版本保持原行为。

批量操作按条提交，可能部分成功。已处理或版本变化的项目不覆盖新版本，结果列出失败，继续处理其余有效项目；不会自动重试。网络断开或认证失效时停止后续项目，未发送项目显示“尚未执行”。结果无法确认时刷新列表核对状态后重新选择。处理中禁用重复确认、取消和关闭；取消未开始的确认面板不会发出审核请求。
