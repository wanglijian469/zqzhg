# 企业入驻与免费展示服务升级：1.10.0+38

2026-10-28。本轮更新本机网站、Go后端及“大陆农机”Flutter代码，独立交付原签名Android验收APK。当前服务模式为 `free_display`，不部署生产、不覆盖正式下载、不制作Linux部署包。

## 修改清单与使用入口

| 功能 | 当前行为与入口 |
| --- | --- |
| 入驻说明 | `/services`，根据需求附件形成正式中英文文案。基础入驻、标准企业展厅、平台内网址、二维码及规定额度内存储免费；基础入驻永久免费，无基础服务年费。网站页脚、登录入驻页、企业工作台和App设置均提供入口。首页保留此前精简布局，不重新加入长篇介绍。 |
| 协议版本 | `/services/showroom-agreement`、`/services/terms`、`/services/privacy`。后台 `/admin/service-documents` 可复制新版本草稿、编辑、预览及发布，已发布正文不能覆盖。保留版本、生效时间、正文摘要和历史确认记录。新注册主动确认用户协议及隐私政策，发布前主动确认三项当前协议，不预选、不为历史企业伪造同意。 |
| 免费存储 | 默认 **200 MB = 200,000,000字节**。更新代码默认值及已保存的系统默认配置；企业独立额度保留。网页设置页按MB配置；Web与App显示已用、预占、总额及剩余量。90%提醒，容量不足拦截新上传。原文件及已保存衍生文件计入容量，迁移副本不重复计量；移除引用不等于删除文件。 |
| 企业核验 | Web工作台 `/merchant/verification`；App工作台快捷入口及设置页。人工审核企业名称、有效统一社会信用代码、营业执照、经办及联系信息；经办人不同于法定代表人时需要授权证明。不强制短信核验，不接入第三方收费认证。后台 `/admin/verifications` 记录查验依据，可通过、驳回或撤销。 |
| 发布限制 | 新企业可保存草稿、上传和预览。提交企业、产品、视频及画册前统一检查企业核验、企业名称匹配和当前协议；管理员代提交同样校验。历史公开版本保留，下次提交修改前补齐。已在审核队列中的提交按原流程完成；后续修改审核期间继续展示已发布版本。 |

| 稳定网址 | 复用 `/v/:slug`、默认历史地址及原有二维码下载分享。正常资料更新不改网址，既有别名规则及历史跳转保留，未入选首页的公开企业继续可搜索。 |
| 工单 | `/service-requests` 和App“投诉与服务申请”。匿名投诉通过随机64位十六进制私密凭证查询；凭证不放进网址。登录企业可申请导出、停展、退出、注销及免费资源调整，服务端绑定本企业。后台 `/admin/service-requests` 受理、反馈、要求补充及结案，带版本冲突校验和审计。企业权益请求由运营人员核验后履行，提交工单不会自动删除资料。 |

| 业务关闭 | 采购、需求发布、询报价、洽谈、撮合及相关后台任务保持关闭，旧 `PROCUREMENT_ENABLED=true` 不能恢复当前版本业务。历史采购表保留。没有新增订单、支付、结算、竞价或收费扩容功能。电话、微信联系继续可用。 |
| 隐私与备案 | 可选访问统计默认关闭，主动开启后才创建统计标识和上报；撤回后停止并清理标识和队列。相机、文件选择按操作申请或调用。保留网站ICP号 `冀ICP备2026047360号-2`；公安、App备案编号独立配置，当前留空，不显示虚构编号或“已备案”。 |

新增管理权限为 `compliance.review`、`service.manage`、`legal.manage`，首页沿用 `home.manage`。管理员可在现有操作员管理中授权。正式文档和私有附件仅按相应权限开放。

## 接口与数据兼容

- Schema从22增量升级至23，新增文档、协议确认、企业核验、工单、私有证据、推荐池及每日名单表，不改写原企业内容、审核快照和媒体引用。升级事务修改系统默认额度，保留每个企业的独立额度。
- 在 `/api/v1` 增加公开文档／历史版本、协议确认、核验、证据附件及工单接口；管理接口使用既有鉴权与权限体系。
- `/public/config` 增加 `service_mode`、文档版本摘要和独立备案字段。存储用量增补 `remaining_bytes` 和额度状态；首页继续使用原 `vendors`、`products` 数据结构，最多返回12家。
- 旧客户端可浏览、登录、保存草稿；注册缺少协议确认或发布缺少核验／当前协议时，服务端返回明确错误。使用新App或网站补齐，不能通过旧接口绕过。旧客户端已有账号和展厅地址保留。
- 系统迁移不会因企业超额自动扣费、下架或删除资料。核验撤销后阻止新提交；违法公开内容由运营人员通过既有下架功能处置并记录原因。

## 安装与回退

- 验收包：`delivery/android-v1.10.0/大陆农机-1.10.0+38.apk`，同目录保存版本与签名清单。验收服务地址为 `http://192.168.179.35:8080`。手机需能访问本机局域网服务；未验证跨设备网络与系统防火墙可达性。
- 全新安装默认使用上述地址；覆盖安装保留已保存的端点，应在App设置中切换到本机验收地址。端点切换沿用原有登出和草稿隔离机制，不让验收操作误写未升级的生产后端。
- 本机运行 `scripts/stop.ps1`、`scripts/start.ps1` 重新构建启动；网站访问 `http://localhost:8080/`。本轮保留启动前公开企业／产品计数和历史地址检查记录，不向真实企业写入测试内容。
- 正式Android下载继续保留原文件，已交付1.9.0验收包也不覆盖。Android通常不允许直接降级版本号；卸载可能清除本机草稿，应先确认云端保存。需要回退时保留原签名，通过具有更高版本号的回退构建处理，或在确认本机资料已保存后另行安排。
- 数据回退优先保留Schema23和新增审计／确认记录；不要删除新表、协议版本或企业文件。免费默认额度可通过后台重新调整。网页界面回退仍保留新后端发布校验，旧界面缺少操作时使用新版网站补齐。
- 本机升级前可执行文件保存在 `.local/free-service-rollback/exhibition-before-schema23.exe`。整体恢复旧后端会失去新增校验，不应直接用于公开服务；确需恢复须先暂停发布、保留新产生数据并核验功能边界，不能直接恢复旧数据库覆盖新资料。
- 未生成网站／Linux部署升级包。本次地图仅检查既有页面布局；未来部署仍须按 `docs/MAP_DEPLOYMENT_REQUIREMENTS.md` 验证真实行政边界、生产路径、下钻、统计与失败重试，本轮不宣称该项生产验收完成。

## 备案合规待确认事项

1. 由运营方与接入服务商核对已提交的实际业务说明、域名及运营主体信息，确认与当前免费企业信息展示功能一致。免费不等于自动免除其他许可要求。
2. 真实App备案编号、公安联网备案编号及对应查询地址尚未提供，系统保持空值；网站现有ICP号也须按实际域名、主体及备案记录核对。不得将网站ICP备案号当作App编号。
3. 人工核验需实际查验营业执照、统一社会信用代码和经办授权，形成可追溯记录；运营方需确定复核、重复主体认领及异常身份处理规则，不能把上传材料自动等同于完成真实身份认证。
4. 运营方需确认安全日志、核验资料、工单、协议及备份的必要保留期间和退出处置规则，落实投诉人员、处理时效、资料导出／账号注销及争议反馈。程序本轮不自动销毁这些记录。
5. 复核实际部署的服务器、OSS、短信渠道、依赖组件和权限使用，与隐私政策保持一致；上线前确认相关数据处理和授权安排。当前验收未接入或核验生产云端资源。
6. 历史采购需求、询价、留言和洽谈属于已停用功能，历史数据保留；如以后恢复，须重新确认业务分类、资质、审核与隐私要求。企业视频／画册展示的业务边界也需按实际内容确认。
7. 正式协议文本需运营方在公开发布／分发前确认；本机已发布版本用于本轮功能验收，不构成已通过ICP备案、App备案、公安备案或完整法律合规审查的结论。
