# 首页配图和企业品牌展厅 · 1.5.8

后台入口 `/admin/featured`，左侧导航改为“首页展示”。页面提供“主视觉配图、企业品牌展厅、精选展品”三个标签，旧地址的 `kind=vendor/product` 仍打开对应选择页。

## 配置平台配图

1. 在“主视觉配图”上传JPEG、PNG或WebP，最多10 MiB；建议16:9、1600×900像素或更大。沿用原图片尺寸校验和压缩，不强制裁剪。
2. 选择文件后可查看本地及服务器预览，分别展示桌面、手机比例；上传有进度，失败保留文件可重试。未成功上传时禁止保存。
3. 上传完成仍为私有图片，点击“保存设置”后才发布到首页。替换或移除也须保存；原平台图片随后不再允许匿名访问，管理员仍可鉴权预览。
4. 保存失败保留上传编号；版本冲突或网络结果不确定时，点击“刷新配置版本”，核对候选图片后再保存，避免重复上传或覆盖他人配置。

首页右侧只展示独立的平台图片，移除企业名牌和展品浮层，不轮播，不随精选厂商变化。未配置或图片加载失败采用工业风占位；上线不自动将某厂商的封面设为平台图。

## 选择品牌展厅

“企业品牌展厅”只列已公开厂商，可搜索、筛选已加入／未加入、查看公开封面、加入或移出首页，并保存排序。计数来自全部已公开精选厂商，不是当前页条数。首页最多12家，排序数字越小越靠前，同值沿用原ID倒序。

待审修改使用原已公开名称和图片。下架立即退出公开首页。既有精选记录不自动取消；旧库超过12家时首页展示前12家，允许移出和调序，新增前需降到上限内。并发新增同样受服务端事务限制。

首页一家为宽幅入口，两家双列，三家以上电脑三列且末行居中；平板两列、手机一列。卡片展示公开封面、完整Logo、名称、主营、地区和进入展厅入口，统一文字区域和按钮位置。精选展品沿用原规则，首页最多8款。

## 接口与数据

- `GET /api/v1/admin/home-display`：`hero_media_id/version/vendor_limit/selected_vendor_count/updated_at`。
- `PUT /api/v1/admin/home-display`：`hero_media_id/version`，编号0移除；版本冲突409 `stale_revision`。
- `POST /api/v1/admin/home-display/media`：管理员专用图片上传，返回原图片上传结构 `id/url/thumb_url`。
- `GET /api/v1/public/home`：新增 `hero:{media_id}`，保留原 `vendors/products/vendor_count`；厂商最多12家，产品仍最多8款。
- 原精选接口新增409 `featured_limit_reached`，保留发布权限、排序和操作日志。

迁移007增加 `home_display_settings` 与 `home_display_media`，可以恢复部分执行并重复运行，不重写已有资料或精选记录。平台上传图片仍放在原媒体目录，上传、登记和日志事务性保存，不占厂商图库限额。管理员保存配置不经过厂商内容审核；只有当前保存的专用平台图片获得匿名访问权限，不放宽原厂商图片权限。

新增日志动作为 `home_display_saved` 和 `home_display_image_uploaded`，后台支持筛选。OpenAPI与网站类型同步更新。

## 交付与恢复

网站与Windows/Linux后端1.5.8，Android保持原签名1.5.2+19。App继续读取原厂商数组，不采用新平台配图，无需重新打包。

升级前备份SQL及媒体，启动后应用迁移007；备份媒体包括平台配图与原企业资源，恢复时SQL和媒体应成套还原。不得单独删除平台媒体登记表。校验清单位于 `delivery/manifest.json`，截图 `screenshots/home-display-*.png`，验收见 [TESTING.md](TESTING.md)。

配置和精选验收仅使用隔离数据库。实际上线配图与厂商选择由管理员配置，本次不自动设置真实厂商的精选状态。
