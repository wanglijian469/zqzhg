## 数量规则

每个厂商最多 **1000 款产品**，包括草稿、待审、公开、驳回及下架记录。图片数和历史版本不消耗额外产品名额。满额后允许修改现有产品；下架本身不释放产品名额。网站及 App 显示中英文提示，超限返回 HTTP 409 / `product_limit_reached`。

创建产品时锁定所属展位并使用当前读检查数量，防止 MySQL 5.7 默认重复读隔离下并发请求超过上限。导入命令使用相同数量检查。

## 导入与备份

先创建应用数据库和媒体配套备份：`.local/backups/before-V0001-import`。正式库中没有加入数量测试的模拟产品。

整理清单：

```powershell
& 'C:/Users/wang_ljian/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' scripts/prepare-vendor-import.py
```

这一步需要 Python 的 `openpyxl`，输出 `.local/imports/V0001.json`；整理后的资料清单与全部导入图片生成 SHA256 指纹。

运行已有后端可执行文件，工作目录必须为 `server`：

```powershell
cd server
./exhibition.exe import-vendor ../.local/imports/V0001.json
```

命令采用数据库事务。任何图片或数据失败都会回滚本次数据库写入并清理本次生成的图片文件；源资料不变时重复执行只返回已有展位，不重复增加产品。源指纹改变时拒绝直接覆盖已有展位。后续资料更新应在核实所属账号后进入正常草稿与审核流程。

导入账号为专用 `import:V0001`，不把资料中的业务电话冒充为已通过验证码验证的厂商登录账号。后台可以查看审核记录、下架及调整精选排序。

随后按用户要求在该账号上配置登录名 `河北冀农农机具有限公司`，可通过公司账号和密码进入 [厂商后台](http://localhost:8080/merchant/login) 修改现有展位及产品，全部内容保持原账号所属关系。详见 [厂商账号说明](MERCHANT_LOGIN.md)。
