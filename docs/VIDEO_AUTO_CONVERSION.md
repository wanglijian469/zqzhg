# 视频由平台自动处理

2026-11-19，用户要求厂商不必理解或自行转换视频编码，并明确将时长上限调整为5分钟。本次替代 OSS 初版“只接受已兼容编码、不转码”的限制。

- 兼容的 H.264／AAC、可分段播放的 MP4 直接复用原文件，不重复编码。
- 常见 MP4／MOV 中不兼容的视频／音频轨由现有 FFmpeg 后台处理；仅音频不兼容时保留视频轨，容器整理使用无损封装。
- 需要视频编码时生成兼容 MP4 展示版；默认最长边1920、不放大低分辨率，保留画面比例；HDR 转为兼容 SDR。原始完整文件私有保留，禁止截断视频来满足限制。
- 时长上限5分钟、单文件200 MiB。私有原件、展示版、封面及公开副本按实际存储计量，沿用企业额度，不能自动扩大额度或自动公开资料。
- 现有 MySQL 租约／心跳／跨进程锁继续使用，同一时间仅一个云文件处理任务；视频编码与滤镜限制为单线程，临时文件受原512 MiB预算及磁盘保留空间限制。处理超时或输出超限会失败并清理半成品，原上传文件保留供重试。
- 页面显示文件上传、后台检查、自动处理进度、封面生成和保存。选择“稍后继续”只退出等待，后台继续；同一文件重新进入时复用上传会话，不重复上传或创建媒体。
- 处理完成仅生成私有可预览文件。企业仍需保存、提交并由平台审核，不自动新建或公开企业视频。

## 配置及接口

`MAX_VIDEO_SECONDS=300`，`OSS_VIDEO_AUTO_CONVERT_ENABLED=true`，`OSS_VIDEO_MAX_OUTPUT_EDGE=1920`。兼容视频不受展示版缩放设置影响。关闭自动转换仅暂停不兼容编码的转换，不影响已处理文件读取。

`GET /api/v1/merchant/files/uploads/:id`（管理员对应 `/admin/storage/files/uploads/:id`）在现有 `state` 上增加可选 `processing_stage`、`processing_percent`。这些为当前 worker 的短期进度，进程重启／其他实例查询时退回通用后台检查提示；任务状态、原件、租约及重试依然持久保存在 MySQL。

没有新增数据库字段或迁移；旧客户端忽略新增进度字段，仍能等待处理结果。处理完成后原件写入已有 StoredObject／企业文件关联，原件预占在同一事务转为实际用量；删除无引用视频会一并清理原件、展示版和封面。

## 验证与回退

自动化覆盖兼容文件原字节复用、MPEG-4转换、PCM音频转换、MOV封装、无音轨、原件保持、输出大小限制、损坏文件、关闭开关、5分钟边界、进度隔离／清理，以及完整上传→转换→计量→删除、退出等待后继续而不重复上传。开发测试使用隔离库和合成文件；真实厂商原片只在ECS内读取／处理，不导出登录令牌或视频。

本次网页和 Linux 后端升级继续携带77项开发边界快照，并执行生产代理和正式HTTPS四级地图、真实统计、手机布局和失败重试检查。APK保持1.12.0+53，旧客户端可使用后台转换；本次未宣称重新打包或安卓真机验收。

普通回退保留 Schema39、媒体、OSS对象和原件关系，可切回此前兼容OSS的程序；不得恢复旧数据库或删除已处理文件。5分钟时长及派一500 MiB的已授权配置保持，不通过回退撤销用户选择。实际部署／真实视频结果另存发布回执。
